# Sumit Kumar Rana – Portfolio

Personal portfolio website of **Sumit Kumar Rana**, a BCA graduate and frontend developer based in Greater Noida West, Uttar Pradesh.

**Live site:** https://sumit-portfolio-blond-six.vercel.app

## About

This site brings together my skills, projects, internship experience and contact details in one responsive page.

## Features

- Responsive layout that works on phones, tablets and desktops
- Light and dark theme switch
- Animated hero section with a typing effect
- Skills and projects with filter tabs
- Expandable experience and education panels
- Scroll progress bar and active menu highlight
- Contact form that sends messages to my email (via Web3Forms)

## Built with

- HTML
- CSS
- JavaScript (no framework)
- Web3Forms for the contact form
- Vercel for hosting

## Projects shown on the site

- **SANTU – Online Learning Platform:** https://santu-online-learning-platform.vercel.app/
- Client websites I worked on during my internship at Softication Technology Pvt. Ltd.: Athlestack.com, Blueclaws-health.com, Alzainresearchgroup.com and Tneinterior.in

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

No installation or build step is needed.
